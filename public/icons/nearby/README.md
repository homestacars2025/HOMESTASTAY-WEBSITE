# "What's nearby" icons

Microsoft **Fluent Emoji — 3D** style, from https://github.com/microsoft/fluentui-emoji
(MIT License, © Microsoft Corporation — full text in `LICENSE-fluentui-emoji.txt`,
which must stay next to these files).

Downloaded once and stored here; never hotlinked. Converted from the 256 px 3D PNGs
to WebP at 96 px (`<key>.webp`) and 48 px (`<key>-48.webp`).

| key         | Fluent Emoji asset          |
|-------------|-----------------------------|
| supermarket | Shopping cart               |
| transit     | Metro                       |
| restaurant  | Fork and knife with plate   |
| pharmacy    | Pill                        |
| hospital    | Hospital                    |
| mall        | Shopping bags               |
| mosque      | Mosque                      |
| atm         | Atm sign                    |

The file names are a contract: the website and the app both load
`/icons/nearby/<key>.webp` and `/icons/nearby/<key>-48.webp`. Do not rename.
